# Contributing

## About mykawa

**mykawa** = my（私の） + kawa（川, river） — "my river."

`generate(seed)` returns a different river every time. Please enjoy your own
3D river!

開発は日本語で、AI（Claude）の助けを借りながら進めています。英語の説明は準備中です。

This project is developed in Japanese, with the help of AI (Claude). An
English write-up is in progress — see [docs/USAGE.md](docs/USAGE.md) for what
exists so far (in Japanese).

You're welcome to use an AI translator (Claude, ChatGPT, Google Translate, etc.)
to read the docs and understand the project. The code itself — identifiers,
comments, docstrings — is already in English; only the surrounding
documentation is Japanese for now.

**Pull requests and issues in English are welcome.**

## How to contribute

1. Fork this repository.
2. Make your change.
3. Open a pull request against `main`, describing what you changed and why.

There's no formal style guide yet. Match the tone of the surrounding code —
see the docstrings in `experiments/mini.py` for the house style: explain
*why* a piece of code exists, not just what it does.
